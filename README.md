# House Price Prediction

This project predicts residential property prices using machine learning techniques on housing data. The workflow includes data cleaning, exploratory data analysis (EDA), feature engineering, handling missing values, feature transformation, and model training.

## Features

* Data preprocessing and missing value handling
* Exploratory Data Analysis (EDA)
* Feature engineering to improve model performance
* Feature scaling and transformation
* Training and evaluation of multiple regression models
* House price prediction on unseen data

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* XGBoost

## Project Workflow

1. Load and explore the dataset
2. Clean and preprocess the data
3. Engineer additional features
4. Train and evaluate regression models
5. Generate predictions on test data

## Results

The project compares different regression approaches and selects the best-performing model based on validation performance.
